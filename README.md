# Interpretable ESG Analytics using Hybrid TP–ANFIS Framework with Adaptive Dynamic Rule Obsolescence (A-DRO)

## Overview
This repository provides the data, models, and implementation supporting a hybrid interpretable AI framework for ESG-based sustainability assessment under uncertainty.

The framework integrates Tensor-Product (TP) modeling, ANFIS, and an Adaptive Dynamic Rule Obsolescence (A-DRO) mechanism for reliability-aware rule evaluation and interpretable ESG decision support.

## Key Contributions
- Hybrid TP–ANFIS interpretable modeling framework
- Compact rule extraction using tensor decomposition
- Comparative analysis of ANFIS vs TP under rule constraints
- Adaptive Dynamic Rule Obsolescence (A-DRO) combining rule obsolescence and prediction surprise
- Reliability-aware rule assessment and adaptive rule management

## Repository Structure
- `/data` – ESG datasets and processed data
- `/code` – MATLAB and Python implementations
- `/models` – Trained models and rule sets
- `/results` – Output data and evaluation results
- `/figures` – Figures used in the manuscript
- `/docs` – Supporting documentation

## Reproducibility
All datasets and code necessary to reproduce the results are included.

## Results Summary
- TP model explains approximately 35% of ESG-return variability using compact rule sets.
- ANFIS achieves R² ≈ 0.74 with the full rule base.
- DRO identifies 254 stable rules (40.64%).
- A-DRO identifies 576 stable rules (92.16%) and 49 adaptive rules (7.84%).
